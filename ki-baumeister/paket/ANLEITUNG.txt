KI-Baumeister – Komplettpaket für Minecraft __MC__ (Fabric)
==========================================================

INHALT
  Installieren.bat          Doppelklick = alles automatisch einrichten
  Installieren.ps1          das eigentliche Installationsskript
  mods\                     KI-Baumeister __MOD__ und Fabric API __FAPI__
  fabric\                   Fabric-Loader-Profil __LOADER__ und offizieller Fabric-Installer (Reserve)
  paket.json                Versionsangaben für das Skript

VORAUSSETZUNGEN
  - Windows 10/11 mit gekauftem Minecraft: Java Edition
  - Der offizielle Minecraft Launcher wurde mindestens einmal gestartet
  - Internet (der Launcher lädt Minecraft und Fabric beim ersten Start, Ollama ca. 1,6 GB)

SO GEHT'S
  1. ZIP vollständig entpacken (nicht direkt im ZIP öffnen).
  2. Minecraft Launcher schließen.
  3. Doppelklick auf "Installieren.bat". Das Skript
       - legt im Launcher das Profil "KI-Baumeister (Fabric __MC__)" an – mit eigenem Spielordner
         %APPDATA%\.minecraft\ki-baumeister, damit deine anderen Profile und Mods unberührt bleiben,
       - übernimmt deine Einstellungen (Sprache, Tasten, Grafik) und kopiert auf Wunsch deine Welten
         (die Originale bleiben unverändert),
       - legt KI-Baumeister und Fabric API in den mods-Ordner des Profils,
       - prüft Ollama: Ist es schon installiert, wird ein vorhandenes passendes Modell genutzt
         oder eines vorgeschlagen (qwen2.5:7b ab 8 GB RAM, qwen2.5:14b ab 24 GB RAM).
         Fehlt Ollama, wird es auf Wunsch heruntergeladen und installiert (ca. 1,6 GB).
     Falls Windows "Der Computer wurde durch Windows geschützt" meldet:
     "Weitere Informationen" -> "Trotzdem ausführen".
  4. Minecraft Launcher öffnen, unten links das Profil "KI-Baumeister (Fabric __MC__)" wählen, "Spielen".
  5. Einzelspielerwelt öffnen (vorher eine Sicherung anlegen!) und K drücken.

IM SPIEL
  - Baumeister-Axt holen: im Menü (K) auf "Axt holen" klicken oder im Kreativ-Inventar unter
    "Werkzeuge & Hilfsmittel". Mit der Axt: Linksklick auf einen Block = Ecke 1,
    Rechtsklick auf einen Block = Ecke 2, Rechtsklick in die Luft = Menü.
    (Ohne Axt: im Menü auf einen Block schauen -> "Ecke 1 setzen" / "Ecke 2 setzen".)
  - Bauwerk beschreiben oder eine Vorlage anklicken -> "KI-Entwurf" (Strg+Enter).
    Die KI plant Typ, Stil, Stockwerke, Dach und Räume, die Engine baut daraus ein komplettes
    Gebäude mit Einrichtung und Garten.
  - Hologramm in der Welt prüfen -> "Bauen". Danebengegangen? -> "Rückgängig".
  - "Variante" zeigt sofort eine andere Ausführung desselben Entwurfs.
  - "Anpassen" ändert den Entwurf, z.B. "drei Stockwerke, Dach aus Kupfer, mit Balkon".
  - "Schematic" speichert das Gebäude als .schem-Datei im Ordner
    %APPDATA%\.minecraft\ki-baumeister\schematics (für WorldEdit / Litematica).

PROBLEME
  - "Ollama offline" im Menü: Ollama über das Startmenü starten (Symbol erscheint unten rechts).
  - "Modell nicht installiert": Eingabeaufforderung öffnen und  ollama pull qwen2.5:7b  eingeben.
  - Spiel stürzt beim Start ab: Im Ordner %APPDATA%\.minecraft\ki-baumeister\mods liegen fremde Mods
    für eine andere Minecraft-Version – diese entfernen (das Skript bietet das an).
  - Welten aus dem normalen Minecraft nutzen: Ordner aus %APPDATA%\.minecraft\saves nach
    %APPDATA%\.minecraft\ki-baumeister\saves kopieren.
  - Manuelle Installation statt Skript: fabric\fabric-installer-*.exe starten (benötigt Java),
    Minecraft __MC__ und Loader __LOADER__ wählen, dann die Dateien aus mods\ nach
    %APPDATA%\.minecraft\mods kopieren und Ollama von https://ollama.com/download installieren.

ENTFERNEN
  - Im Launcher unter "Installationen" das Profil "KI-Baumeister" löschen.
  - Den Ordner %APPDATA%\.minecraft\ki-baumeister löschen (enthält auch die Welten dieses Profils!).
  - Ollama bei Bedarf über "Apps & Features" deinstallieren.
